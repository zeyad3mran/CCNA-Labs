# CCNA Labs

80 hands-on CCNA labs (10 per week) plus a project at the end of each week, built with Cisco Packet Tracer / GNS3. Each lab folder has the topology, sanitized configs, verification output and troubleshooting notes.

| Week | Topic | Labs | Project |
|------|-------|------|---------|
| 1 | [Network Fundamentals & Addressing](week-01-network-fundamentals-addressing/) | 10 | Small Company Network with VLSM |
| 2 | [Switching & VLANs](week-02-switching-vlans/) | 10 | Multi-Department Campus with Inter-VLAN Routing |
| 3 | [Layer 2 Redundancy & Security](week-03-layer-2-redundancy-security/) | 10 | Redundant Campus with Secured Access Layer |
| 4 | [IP Routing](week-04-ip-routing/) | 10 | Multi-Site WAN with OSPF |
| 5 | [IP Services](week-05-ip-services/) | 10 | Branch Internet Access with DHCP, NAT & HSRP |
| 6 | [Network Security](week-06-network-security/) | 10 | Secured Enterprise Network with ACLs |
| 7 | [IPv6 & Automation](week-07-ipv6-automation/) | 10 | Dual-Stack Network with Automated Backups |
| 8 | [Review, Troubleshooting & Final](week-08-review-troubleshooting-final/) | 10 | FINAL PROJECT: Full Enterprise Network |

## Tools
Cisco Packet Tracer, GNS3, Python (Netmiko), Ansible, Git

## Notes
- Passwords and secrets are removed from all configs.
- Python/Ansible labs (Week 7) run on a Linux/Windows machine against lab devices.
